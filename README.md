# 포켓몬 랜덤 디펜스

포켓몬을 소환하고 합성해 길 위의 적을 막는 랜덤 타워 디펜스. 관동·성도·호연 체육관 8곳씩(지방마다 40웨이브)과 사천왕·챔피언이 나오는 챔피언로드(25웨이브).

판 안에는 파트너, 지닌 물건, 포획, 미션, 야생 강적, 운 뽑기, 메가진화, 특수 조합이 있고, 판 밖에는 도감, 업적과 출발 지원, 챔피언 랭크 1~10, 관장 별, 오늘의 도전, 규칙 도전, 주간 전설 레이드, 끝없는 모드가 있다.

## 실행

정적 파일이라 아무 웹 서버로 열면 된다. 스프라이트를 따로 불러오므로 `file://`보다 서버가 안전하다.

```
python3 -m http.server 8000
# http://localhost:8000/
```

## 파일 구조

| 경로 | 내용 |
|---|---|
| `index.html` | 일반 웹페이지(GitHub Pages). `tools/build.py`가 만든다 |
| `artifact.html` | claude.ai 아티팩트용 본문(문서 머리 없이). 같은 스크립트를 쓴다 |
| `src/head.html`, `src/body.html` | 위 두 페이지의 원본 |
| `css/game.css` | 화면 전체 스타일 |
| `js/sprites.js` | 스프라이트 좌표(자동 생성) |
| `js/data.js` | 타입 상성, 계열(LINES), 특성, 트레이너 덱, 전설, 성격 |
| `js/regions.js` | 지방 데이터: 체육관, 도시 배경, 적 풀, 관장마다 바뀌는 판 모양, 규칙(성도 낮과 밤, 호연 날씨) |
| `js/core.js` | 상태, 능력치 계산, 판·길 기하와 배경, 웨이브 진행, 공격과 피해 |
| `js/skills.js` | 고유 스킬 표와 발동 |
| `js/content.js` | 판 안 콘텐츠: 랭크·규칙·출발 지원, 파트너, 지닌 물건, 메가진화, 특수 조합, 포획, 야생 강적, 운 뽑기, 미션, 일찍 부르기, 길 바꾸기, 레이드, 안내 카드, 오박사 |
| `js/ui.js` | 소환·합성·판매, 보상과 상점, 기록과 이어하기, 덱·결과·메뉴 화면, HUD |
| `js/meta.js` | 도감, 업적, 타이틀·지방·도전 모드 화면, 모드별 기록 |
| `js/render.js` | 캔버스 그리기, 파티클, 배너, 포획 볼, 날씨 |
| `js/scene.js` | 전장 분위기: 바람 입자, 구름 그림자, 빛, 스킬 컷인, 외곽 소품 |
| `js/main.js` | 효과음, 배경음악, 입력, 메인 루프, 시작 |
| `sprites/anim-*.webp` | 움직이는 스프라이트 묶음(1024px 폭, 파일 이름에 내용 해시) |
| `sprites/thumbs.webp` | 정지 썸네일 묶음(96px 칸) |

스크립트는 모듈이 아닌 일반 스크립트로, 위 순서대로 읽는다. 맨 위 `const`/`let`은 파일끼리 공유된다.

## 스프라이트 다시 만들기

PokeAPI/sprites의 Showdown 움직이는 GIF를 `gifs/{도감번호}.gif`로 받아 둔 뒤:

```
python3 tools/build_sprites.py gifs . ids.json
python3 tools/build.py
```

## 지방 추가하기

`js/regions.js`의 `REGIONS`에 항목을 넣는다. 판 모양은 `variants`에 여러 개를 두고, 관장을 하나 이길 때마다 다음 모양으로 바뀐다. 각 모양은 `path(o,C,R)`가 돌려주는 닫힌 점 목록(칸 단위)과, 길이 지나가는 칸 번호 목록 `closed`로 이뤄진다.
