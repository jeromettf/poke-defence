# 포켓몬 랜덤 디펜스

포켓몬 랜덤 타워 디펜스. 파일 하나(`index.html`)로 동작하고, 브라우저로 열면 바로 플레이할 수 있어요.

- 관동 체육관 8곳, 40웨이브. 5웨이브마다 관장전, 이기면 배지 패시브
- 트레이너 덱 6종(지우, 레드, 그린, 목호, 성호, 난천) 또는 10계열 중 5계열 직접 고르기
- 36계열, 역할 5종(딜러, 광역, 제어, 지원, 특수), 계열 강화
- 서로 다른 3단계 3마리로 전설 합체. 기준 포켓몬의 타입이 전설을 정함(12종)

## 조작

- 소환: 덱에서 1단계 포켓몬이 무작위로 나와요
- 같은 포켓몬·같은 단계를 끌어다 겹치면 진화
- 포켓몬을 누르면 정보 창, 오른쪽 위 메뉴에서 멈춤·소리·규칙

## 자료

포켓몬 스프라이트는 [PokeAPI/sprites](https://github.com/PokeAPI/sprites)의 Showdown 애니메이션 스프라이트를 줄여 파일 안에 넣었어요. 포켓몬 관련 저작권은 Nintendo, Creatures, GAME FREAK에 있고, 이 저장소는 개인 비상업 용도예요.
